# 资源限制离线分析实验

## 实验概述

本实验用于测试不同资源约束（CPU、内存、GPU、GPU内存）下机器学习模型的性能表现。实验支持多种AI任务，包括图像超分辨率、图像描述和目标检测，通过参数配置Docker Container的方式来测试不同资源配置组合的影响。

## 实验快速启动方式

```bash
make run
```

## 实验脚本解释

### 任务执行

#### inference.py

多种 DNN 网络计算任务的执行脚本，该文件将映射到容器内用于执行 DNN 模型的推理

#### qwen.py

LLM 推理的执行脚本，该文件可映射到容器用于LLM的推理执行

### 批量执行

#### generate_resource_configs.py

该文件用于生成批量执行需要的所有配置组合，并将组合记录在 `json` 文件中

#### run_experiment.py

利用上述脚本生成的 `json` 文件启动子进程执行 docker 中的计算过程，并将实验结果记录在 `csv` 文件中
